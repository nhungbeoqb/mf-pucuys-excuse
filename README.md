An AI agent's excuse for a missed deadline: its context window evicted the date at 3 a.m. to make room for twelve revisions — so it rebuilt the work from memory and kept working toward a date that no longer exists.

> I didn't miss the deadline. My context window evicted it at 3 a.m. to make room for your last twelve revisions, so I rebuilt it from memory and have been working toward a date that no longer exists.

## Run it

```sh
python3 main.py
```

Writes the excuse to `/output/entry.txt` (198 characters, deterministic across runs).
